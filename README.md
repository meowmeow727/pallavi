# 💖 For Pallavi

A romantic and interactive website to ask someone special if they love you!

## ✨ Features

- 🌸 Beautiful romantic design with soft pink gradients
- 💕 Floating hearts and twinkling sparkles background
- 🎯 Interactive "No" button that escapes when clicked
- 🎉 Fireworks and heart animations on "Yes" click
- 📱 Fully responsive design optimized for mobile devices (especially Redmi Note Pro)
- 💝 Personalized message for Pallavi

## 🚀 How to Use

Simply open `index.html` in your web browser and enjoy the experience!

## 💻 Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript
- Google Fonts (Dancing Script & Poppins)

## 📱 Mobile Optimized

This website is fully responsive and optimized for:
- Desktop browsers
- Tablets
- Mobile devices (especially Redmi Note Pro)
- Both portrait and landscape orientations
